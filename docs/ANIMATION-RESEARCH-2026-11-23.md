## 2. Browser export comparison

For canvas-based options, the common capture path is to draw or composite into an origin-clean `HTMLCanvasElement` or `OffscreenCanvas`, then create a `VideoFrame` with the studio’s timestamp. WebCodecs exposes these APIs in secure windows and dedicated workers, subject to codec support. The studio should supply one amplitude sample per output frame to a trusted property mapper. The ratings below assess those adapters using **frame-indexed scene state** as the acceptance criterion. Pixel and encoded-byte parity require separate tests. ## 3. Godot 4.x in practice

- **Fixed delta from startup works at the engine level. Host-driven whole-engine stepping has no public Web API.** The shell forwards startup arguments, including `--fixed-fps`, to the engine. The 4.7.2 Web entry point still schedules iterations through Emscripten’s browser animation loop. A fixed simulation delta therefore leaves browser scheduling in place. [Shell argument forwarding](https://github.com/godotengine/godot/blob/4.7.2-stable/platform/web/js/engine/engine.js#L138) · [Fixed-FPS engine code](https://github.com/godotengine/godot/blob/4.7.2-stable/main/main.cpp#L4569) · [Web main loop](https://github.com/godotengine/godot/blob/4.7.2-stable/platform/web/web_main.cpp#L809) · [Emscripten scheduling](https://emscripten.org/docs/api_reference/emscripten.h.html#c.emscripten_set_main_loop)
- **A custom scene-level bridge is possible in principle.** Trusted GDScript can accept `t` and amplitudes via `JavaScriptBridge`, seek an `AnimationPlayer`, and request a draw. `force_draw()` draws the scene while engine logic continues on its own loop. JavaScript can wrap the resulting HTML canvas in `VideoFrame`. An acknowledgement tied to the completed draw and repeatable capture in this PWA are **UNVERIFIED**. The stock shell takes an HTML canvas. Threaded Web builds require cross-origin isolation. [JavaScriptBridge](https://docs.godotengine.org/en/stable/classes/class_javascriptbridge.html) · [Animation seek](https://docs.godotengine.org/en/stable/classes/class_animationplayer.html#class-animationplayer-method-seek) · [Force draw](https://docs.godotengine.org/en/stable/classes/class_renderingserver.html#class-renderingserver-method-force-draw) · [Web requirements](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html) · [VideoFrame](https://www.w3.org/TR/webcodecs/#videoframe-interface)

Actual recording and output retrieval in a stock Web export are **UNVERIFIED**. Movie Maker writes files and supplies no JS frame-step or WebCodecs interface.
